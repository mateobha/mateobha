# Hi, I'm Mateo 👋

I build solutions at the intersection of artificial intelligence, software
engineering, data science and biotechnology.

## About me

Data Scientist with a Master's degree in Applied Artificial Intelligence and
experience in machine learning, research, and software development. I work
end-to-end with data — from collection, cleaning, and integration to analysis,
model development, and deployment.

🔭 **What I'm working on**
- Machine learning & deep learning: classical ML and neural networks (CNNs,
  feed-forward) for prediction and classification on tabular, image, and signal data
- GenAI & LLM workflows: prompt engineering, RAG, semantic search, NER, and
  fine-tuning with the OpenAI and Anthropic APIs
- Agentic coding & automation: hands-on with Claude Code to automate document
  processing, data extraction, and dev workflows
- Applied data science: inverse problems, Bayesian statistics, and end-to-end
  pipelines from raw data to deployed models
- Co-Lead of the EU–CELAC "AI for ID & AMR" initiative, building AI models to
  predict the emergence of infectious diseases and antimicrobial resistance
- Previously built computer vision systems at Forschungszentrum Jülich

💼 Looking to grow as a Data Scientist / ML Engineer, turning data into
high-impact, deployed solutions.
